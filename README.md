# ProTaxi

**Таксі показує тобі виручку. Але виручка — це не твої гроші.**

ProTaxi рахує, скільки з кожної зміни справді залишається водієві: мінус комісія
платформи, мінус еквайринг, мінус пальне по факту, мінус оренда авто, мінус те,
що варто відкласти на ремонт. Одна велика цифра — **«на руки»**.

**Відкрити:** https://aa-ua.github.io/ProTaxi/

## Що вміє

**Гроші.** Кожне замовлення з часом і одометром — кілометри рахуються по факту,
а не по картах. Комісія платформи, еквайринг з карткових оплат, чайові зі здачею,
податки. Скільки завгодно сесій за день: обід чи перерва не ламають статистику.

**Світлофор замовлень.** Кожне замовлення підсвічується проти твого середнього
темпу: зелене — вигідніше, червоне — ти на ньому втрачаєш. Тап показує, наскільки
саме.

**Пальне.** Витрата рахується від повного бака до повного, з реальних чеків
заправок — а не «приблизно». Каністра показує, скільки лишилось і на скільки
кілометрів вистачить. Окремо видно, скільки грошей уже накопичено на наступну
заправку.

**Оренда і знос.** Орендуєш авто — вкажи суму за день, тиждень чи місяць, і вона
знімається сама. Своє авто — відкладай на ремонт відсотком від чистого або
гривнями за кожен кілометр.

**Мапа.** Маршрут кожного замовлення прокладається по реальних дорогах, а вулиці
фарбуються за тим, скільки ти на них заробляєш за годину. Плюс аналітика по
годинах, днях тижня й напрямках.

**Ціль дня.** Скільки лишилось і скільки це приблизно замовлень. Поки витрати за
день не відбиті — застосунок прямо про це пише.

## Як влаштовано

Один файл `index.html` — без збірки, без залежностей, без сервера. Дані живуть
у браузері на телефоні й нікуди не відправляються.

Працює як звичайний сайт і як застосунок усередині Telegram.

## Резервні копії

Дані зберігаються в браузері й привʼязані до адреси сайту. Хмарних копій немає —
є ручна копія у файл або через буфер обміну: «Ще» → «Резервна копія».

Роби копію після кожної зміни, поки не зʼявиться синхронізація.
